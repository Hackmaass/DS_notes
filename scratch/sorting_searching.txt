Set 1: Library Management System
Problem 1 Prepare a ranked list of the most-issued books based on the number of times each book was issued. Implement:
a. Selection sort for descending issue count
b. Insertion sort and count the number of shifts
c. Display the top 5 most-issued books
Set2  For the library office, search a book record (Book ID, Title, Author). Implement:
a. Linear search by Title
b. Binary search by Book ID (sort the records first)
c. Display the number of comparisons for each search
Problem 3 (Quick Sort, CO2) Arrange the fine amounts collected from members using Quick Sort. Implement:
a. Partition the list
b. Recursively apply Quick Sort
c. Display the sorted fine list
Problem 4 (Selection and Bubble Sort, CO2) Store the prices of books in an array. Write functions for sorting the array of floating-point numbers in ascending order using:
a. Selection Sort
b. Bubble Sort, and display the five highest prices
